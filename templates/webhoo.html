🔗 Webhook Endpoint (n8n Target)

Gunakan URL dan panduan di bawah ini untuk mengonfigurasi HTTP Request Node pada n8n atau Make.com.

🌐 URL Endpoint Utama

Memuat Webhook URL...

* Method yang didukung: POST

🔑 Otentikasi (Header)

Untuk alasan keamanan, setiap request wajib menyertakan API Key pada Header request Anda.

Key: X-API-Key
Value: TREND_XXXXXXXXXXXXXXXX

📦 Format Payload JSON (Body)

Kirimkan data dalam bentuk format JSON murni. Pastikan properti "platform" sesuai dengan tujuan (contoh: tiktok, youtube, instagram, linkedin).

{
  "platform": "tiktok",
  "status": "PUBLISHED",
  "details": {
    "media_url": "https://url-penyimpanan-video.com/video_anda.mp4",
    "caption": "Video diposting otomatis via n8n 🚀",
    "hashtag": "#automation #trendora"
  }
}

Privacy Policy

TRENDORA AUTOMATION Inc. • Terakhir Diperbarui: 2 Agustus 2026

Keamanan dan privasi data Anda adalah prioritas kami. Kebijakan Privasi ini menjelaskan bagaimana TRENDORA AUTOMATION mengumpulkan, menggunakan, menyimpan, dan melindungi informasi pribadi Anda saat menggunakan platform kami.

1. Informasi yang Kami Kumpulkan

  • Informasi Akun: Nama lengkap, alamat email, dan kredensial keamanan 2FA (Secret Key).
  • Data Otentikasi (OAuth 2.0): Saat Anda menghubungkan media sosial (TikTok, YouTube, dsb), kami menyimpan Access Token dan Refresh Token otorisasi secara aman. Kami TIDAK menyimpan kata sandi media sosial Anda.
  • Data Transaksi: Status berlangganan, riwayat tagihan. Kami menggunakan Midtrans sebagai Payment Gateway; detail kartu kredit Anda diproses oleh mereka dan TIDAK pernah menyentuh server kami.
  • Log & Data Penggunaan: Alamat IP, log aktivitas postingan API (timestamp, platform, payload caption, URL video), serta metrik interaksi pada web dashboard kami.

2. Penggunaan Informasi Data Anda

Kami menggunakan data yang dikumpulkan semata-mata untuk:

  • Mengoperasikan fungsi inti automasi posting (melakukan otorisasi API ke platform pihak ketiga atas nama Anda).
  • Menyediakan dukungan teknis (Customer Support) dan memperbaiki bug sistem.
  • Mendeteksi, mencegah, dan menangani masalah keamanan, *spam*, atau penyalahgunaan API.

3. Pengungkapan Kepada Pihak Ketiga

Kami tidak akan pernah menjual, menyewakan, atau memperdagangkan data pribadi maupun kredensial token Anda kepada pihak ketiga. Informasi hanya dapat diungkapkan kepada penyedia layanan cloud (seperti server hosting kami) yang terikat oleh perjanjian kerahasiaan, atau jika diwajibkan secara hukum oleh pihak berwenang sesuai undang-undang yang berlaku.

4. Keamanan Data

Kami menerapkan langkah-langkah keamanan Standar Industri, termasuk enkripsi SSL/TLS pada semua transmisi jaringan (HTTPS), perlindungan berbasis algoritma hashing satu arah, dan pembatasan akses database yang ketat. Walaupun begitu, tidak ada metode transmisi di Internet yang 100% aman; kami berusaha keras untuk menjaga data Anda namun tidak dapat memberikan jaminan keamanan mutlak.

5. Hak-Hak Pengguna (Sesuai UU PDP No. 27/2022)

Sebagai Subjek Data, Anda memiliki hak penuh atas informasi pribadi Anda, termasuk:

  • Akses & Pembaruan: Mengakses dan memperbarui informasi akun Anda kapan saja.
  • Pencabutan Akses: Mencabut otorisasi (Revoke Access) media sosial langsung dari dasbor platform.
  • Hak Penghapusan (Right to be Forgotten): Meminta penghapusan permanen seluruh data Anda dari server kami dengan menghubungi tim dukungan kami.

6. Retensi & Penyimpanan Data

Data pribadi dan log akses disimpan di server kami hanya selama akun Anda berstatus aktif, atau selama diperlukan untuk memenuhi kewajiban hukum, menyelesaikan sengketa, dan menegakkan perjanjian kami. Log aktivitas API lama umumnya akan dihapus secara berkala secara otomatis.

7. Kebijakan Terhadap Anak-Anak (COPPA)

Layanan kami tidak ditujukan untuk individu di bawah usia 13 tahun. Kami tidak dengan sengaja mengumpulkan Data Pribadi dari anak-anak di bawah 13 tahun. Jika Anda adalah orang tua atau wali dan mengetahui bahwa Anak Anda telah memberikan Data Pribadi kepada kami, harap hubungi kami.

8. Perubahan pada Kebijakan Privasi

Kami berhak untuk memperbarui Kebijakan Privasi ini dari waktu ke waktu. Kami akan memberi tahu Anda mengenai perubahan yang signifikan melalui pemberitahuan email atau pengumuman penting di dashboard aplikasi sebelum perubahan tersebut berlaku efektif.

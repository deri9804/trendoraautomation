User Data Deletion Instructions

Petunjuk Penghapusan Data Pengguna dari Sistem TRENDORA

Sesuai dengan Aturan Privasi Meta (Facebook/Instagram) dan GDPR, kami menghormati hak Anda untuk menghapus informasi pribadi dan memutus koneksi media sosial Anda dari platform TRENDORA AUTOMATION kapan saja.

Opsi 1: Menghapus Akses secara Mandiri

Jika Anda hanya ingin memutuskan tautan antara akun Facebook/Instagram Anda dengan sistem kami (Mencabut Akses Token), ikuti langkah berikut:

  1. Login ke akun Facebook Anda.
  2. Buka menu Pengaturan & Privasi > Pengaturan.
  3. Di menu sebelah kiri, klik Keamanan dan Login lalu cari Integrasi Bisnis atau Aplikasi dan Situs Web.
  4. Cari aplikasi "Trendora Automation", centang kotak di sebelahnya, lalu klik tombol Hapus.

Opsi 2: Permintaan Penghapusan Data Penuh (Akun & Log)

Jika Anda ingin kami menghapus seluruh data Anda secara permanen dari server dan database (Google Sheets) kami, termasuk API Key, riwayat log postingan, dan status akun, silakan kirimkan permohonan tertulis kepada kami.

Kirimkan Email Ke: deripernandi99@gmail.com

Format Email:

  • Subjek: Request Penghapusan Data - [Email Akun Anda]
  • Isi Pesan: Mohon hapus seluruh data saya yang terkait dengan email akun ini dari sistem TRENDORA.

* Kami akan memproses permintaan Anda dan menghapus data secara permanen dalam waktu maksimal 2x24 jam hari kerja, lalu mengirimkan email konfirmasi kembali kepada Anda.

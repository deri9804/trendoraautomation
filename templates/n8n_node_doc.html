🔌 n8n Custom Community Node

Gak perlu lagi rakit HTTP Request manual dengan Header & OAuth rumit. Pakai official community node kami!

1. Install Node

Di n8n kamu, masuk ke Settings > Community Nodes, lalu ketik n8n-nodes-automedia.

2. Masukkan API Key

Buka AutoMedia Credentials di n8n, lalu paste API Key yang kamu dapat dari Dashboard web ini.

3. Drag & Auto Post

Tarik node AutoMedia ke canvas, pilih target platform (Reels/TikTok/Shorts), lalu eksekusi workflow!
